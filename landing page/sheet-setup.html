How It Works

A small Google Apps Script bound to your sheet acts as a web API. YoBotz calls it with your token → gets your product list as JSON → syncs to products.json.

No OAuth2 or GCP needed. The script runs as you, so it reads your private sheet directly.

function doGet(e) {
  var token = e.parameter.token;
  var SECRET_TOKEN = "my_bakery_bot_secret_token_2026";

  if (token !== SECRET_TOKEN) {
    return ContentService.createTextOutput(JSON.stringify({error: "Unauthorized"}))
                         .setMimeType(ContentService.MimeType.JSON);
  }

  var sheet = SpreadsheetApp.getActiveSpreadsheet()
                   .getSheetByName("Bakery Products Inventory V4");

  var data = sheet.getDataRange().getValues();
  var headers = data[0];
  var rows = [];
  for (var i = 1; i < data.length; i++) {
    var row = {};
    for (var j = 0; j < headers.length; j++) {
      row[headers[j]] = data[i][j];
    }
    rows.push(row);
  }

  return ContentService.createTextOutput(JSON.stringify(rows))
                       .setMimeType(ContentService.MimeType.JSON);
}

3. Deploy in Google Sheets

Open your sheet → Extensions → Apps Script
2
Delete placeholder code, paste your script from above, click Save
3
Click Deploy → New deployment
4
Type: Web app
5
Who has access: "Anyone"
6
Click Deploy, authorize when prompted
7
Copy the Web App URL shown after deployment — paste it in the field at the top of this page. Then click Test Connection to verify.

Syncing

  • Manual: POST /admin/{business}/sync-products
  • Offline resilient — uses last cached products.json
  • Token stored in business vault, never in config files
